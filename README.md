### 1. CI/CD (GitHub Actions)
**Задача:** Реализовать две независимые джобы в одном workflow.  
**Решение:**  
- Первая джоба выводит текущую директорию (`pwd`).  
- Вторая запускает скрипт `Privet mur.sh` (лежит в папке `forjob/`).  
**Что показал:** Понимание основ CI, синтаксиса YAML, запуска скриптов в окружении GitHub.

**📂 Смотреть:** [.github/workflows/](.github/workflows/)

### 2. Bash — автоматизация 
**Задача:** Выполнить серию команд в терминале Linux: переходы, создание папок/файлов, работа с vim, поиск строки (`grep`), перенаправление вывода, копирование между папками.  
**Решение:** Все команды описаны в `bash_command/tasks.txt` с пояснениями.  
**Плюс:** Написан скрипт `bash_script/reminder.sh`, который создаёт файл с именем вида `2025-03-30_Важное напоминание`.  
**Что показал:** Уверенное владение командной строкой, умение автоматизировать.

**📂 Смотреть:** [bash_command/](bash_command/), [bash_script/](bash_script/)

### 4. Charles Proxy — подмена трафика
**Задача:** Научиться изменять ответы сервера в реальном времени.  
**Решение:**  
1. **Подмена статус-кода**  через инструмент Rewrite.  
2. **Подмена тела ответа** через Map Local (подставил свой JSON).  
3. **Удаление заголовка** через Breakpoint.  
**Что показал:** Понимание работы HTTP, умение отлаживать и тестировать негативные сценарии.

**📂 Смотреть:** [charles/](charles/) (скриншоты с пояснениями)

### 6. API-тестирование (Postman + Newman)
**Задача:** Протестировать REST API [Restful Booker](https://restful-booker.herokuapp.com/).  
**Что сделано:**  
- Создана коллекция запросов (GET, POST, PUT, DELETE).  
- Настроено окружение (base URL, токены).  
- Запуск коллекции через Newman в Windows — вывод сохранён в `Newman.txt`.  
**Что показал:** Владение Postman, написание тестов (pm.test), работа с переменными, CI-запуск.

**📂 Смотреть:** [postman/](postman/)  
- Коллекция: `Restful Booker Project Qa.postman_collection.json`  
- Окружение: `Serve Rest.postman_environment.json`
- Вывод результат запуска колекции через СMD `Newman.txt`
